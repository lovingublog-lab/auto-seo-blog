메신저나 검색 결과에서 링크를 눌렀는데 브라우저 대신 쇼핑앱, 지도앱, 동영상앱처럼 예상하지 않은 앱이 바로 열릴 때가 있습니다. 링크 자체가 잘못된 경우도 있지만, 더 흔한 원인은 **예전에 선택한 앱 연결이 기본값처럼 남아 있거나 해당 앱이 특정 링크 형식을 맡도록 설정된 상태**입니다.

이 문제를 풀 때는 기본 앱을 전부 초기화하기보다 **어떤 링크에서, 어떤 앱이, 어떤 조건으로 자동 실행되는지**를 먼저 확인하는 편이 안전합니다. 운영체제와 제조사에 따라 메뉴 이름은 다를 수 있으므로 화면 이름보다 연결 관계를 보는 것이 중요합니다.

## 같은 주소처럼 보여도 링크 종류가 다를 수 있다

브라우저에서 보는 일반 웹주소와 특정 앱 안의 화면으로 바로 이동하는 링크는 겉보기에는 비슷해도 동작 방식이 다를 수 있습니다. 예를 들어 웹에서도 열 수 있는 상품·지도·영상 주소가 설치된 앱과 연결되어 있다면, 휴대폰은 브라우저 대신 해당 앱으로 보내려 할 수 있습니다.

문제가 생긴 링크의 주소를 복사할 수 있다면 실제 주소를 확인해 봅니다. 같은 서비스의 다른 링크도 모두 엉뚱한 앱으로 열리는지, 특정 링크 하나에서만 그러는지도 비교합니다.

**모든 링크가 같은 앱으로 가면 앱 연결 설정을 의심할 이유가 크고, 특정 주소 하나만 이상하면 그 링크 자체의 이동 방식이 다른지**를 보는 쪽이 맞습니다.

## ‘이번 한 번’과 ‘항상’ 선택은 결과가 크게 다르다

앱을 여러 개 설치한 휴대폰에서는 링크를 처음 열 때 어떤 앱을 사용할지 묻는 화면이 나타날 수 있습니다. 이때 한 번만 사용할 앱을 고르는 선택과 앞으로 같은 종류의 링크를 계속 맡길 앱을 고르는 선택이 구분되어 있는 경우가 있습니다.

문제는 급하게 눌렀던 선택을 기억하지 못한 채 이후부터 선택창이 사라졌을 때입니다. 이 상태에서 앱을 삭제했다가 다시 설치하거나 브라우저 설정 전체를 초기화하면 원인은 가릴 수 있어도 다른 기본 연결까지 바뀔 수 있습니다.

따라서 “선택창이 예전에는 떴는데 지금은 안 뜬다”면 **잘못 연결된 앱 하나의 기본 연결 기록부터 확인하는 것**이 범위를 가장 작게 잡는 방법입니다.

## 기본 브라우저 문제와 특정 링크 연결 문제를 나눠 본다

모든 웹주소가 원하지 않는 브라우저에서 열린다면 기본 브라우저 선택 문제에 가깝습니다. 반대로 일반 웹페이지는 원하는 브라우저에서 열리는데 특정 서비스 주소만 앱으로 넘어간다면, 브라우저 자체보다 **그 서비스 앱의 링크 연결**을 확인해야 합니다.

이 둘을 구분하지 않으면 기본 브라우저를 바꿨는데도 특정 링크는 계속 앱으로 열리는 상황이 생길 수 있습니다.

간단한 비교는 두 가지 주소로 할 수 있습니다.

- 평범한 뉴스나 검색 페이지처럼 앱과 직접 연결되지 않은 웹주소
- 문제가 반복되는 서비스의 주소

첫 번째는 원하는 브라우저에서 열리고 두 번째만 특정 앱으로 간다면, 손볼 범위는 기본 브라우저 전체가 아니라 해당 앱 쪽일 가능성이 높습니다.

## 잘못 연결된 앱 하나만 되돌리는 순서

휴대폰 설정에서 해당 앱의 정보 화면이나 기본 연결 관련 항목을 열면, 이 앱이 어떤 링크를 자동으로 열도록 되어 있는지 확인하거나 기본 동작을 지울 수 있는 경우가 있습니다. 메뉴 이름은 기기와 운영체제 버전에 따라 기본값, 링크 열기, 기본 앱, 지원되는 링크처럼 다르게 표시될 수 있습니다.

여기서 중요한 것은 **모든 앱 설정을 초기화하지 않고 문제를 일으키는 앱 하나만 대상으로 바꾸는 것**입니다.

변경했다면 곧바로 여러 설정을 더 만지지 말고, 원래 문제가 있던 링크를 다시 눌러 결과를 확인합니다. 선택창이 다시 나타나거나 브라우저에서 정상적으로 열린다면 원인이 앱 연결 기록 쪽이었다고 볼 수 있습니다.

반대로 아무 변화가 없다면 설정을 더 초기화하기 전에 다른 가능성을 봐야 합니다.

## 앱 안에서 누른 링크는 그 앱의 자체 브라우저일 수도 있다

메신저, SNS, 메일 앱 가운데 일부는 링크를 눌렀을 때 별도의 브라우저 앱으로 넘기지 않고 **앱 내부에 웹화면을 띄우는 방식**을 사용합니다. 이 경우 주소창 모양이 평소 브라우저와 다르거나, 화면 위쪽에 앱 이름이 계속 남아 있을 수 있습니다.

이 상태를 “엉뚱한 앱이 열렸다”고 생각해 기본 앱을 바꿔도 동작이 달라지지 않을 수 있습니다. 앱 내부 화면에 브라우저에서 열기와 비슷한 기능이 있다면 외부 브라우저로 넘겼을 때 결과가 달라지는지 비교해 볼 수 있습니다.

즉 **링크를 연 주체가 운영체제인지, 원래 사용하던 앱 내부 기능인지**도 구분해야 합니다.

## 바꾼 뒤에는 같은 링크 하나로 재현 시험을 한다

설정을 바꾼 뒤에는 여러 앱을 오가며 확인하기보다 처음 문제가 생겼던 링크 하나를 기준으로 시험합니다.

1. 문제가 생긴 링크를 다시 연다.
2. 어떤 앱이나 화면이 실행되는지 본다.
3. 선택창이 나타난다면 원하는 앱을 우선 한 번만 선택해 본다.
4. 동작이 맞는 것을 확인한 뒤에만 계속 사용할 기본 연결을 정한다.

이렇게 하면 잘못된 선택을 다시 고정할 가능성을 줄일 수 있습니다.

링크 문제는 앱이 고장 난 것처럼 보여도 실제로는 **링크 종류, 기본 앱, 특정 앱의 자동 연결, 앱 내부 브라우저** 가운데 하나에서 갈리는 경우가 많습니다. 전부 초기화하기 전에 어느 단계에서 다른 앱으로 넘어가는지 하나씩 확인하면 필요한 설정만 바꿀 수 있습니다.
