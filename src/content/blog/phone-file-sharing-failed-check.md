휴대폰에서 사진이나 PDF를 보내려는데 공유 화면이 멈추거나, 보냈다는 표시가 나왔는데 상대방은 파일을 열지 못할 때가 있습니다. 둘 다 '파일 공유가 안 된다'고 느껴지지만 해결할 위치는 다릅니다. **전송하기 전에 멈춘 것인지, 전송 도중 실패했는지, 전달된 뒤 상대방이 열지 못하는지**를 구분하면 불필요하게 앱을 지우거나 파일 형식을 바꾸지 않아도 됩니다.

가장 중요한 원칙은 **원본을 그대로 두고 작은 테스트 파일 한 개로 원인을 좁히는 것**입니다. 전송 오류가 난다고 원본을 삭제하거나 클라우드 폴더에서 이동하면 나중에 복구할 여지가 줄어듭니다.

## 오류가 생긴 화면이 진단의 출발점

공유 문제를 세 단계로 나눠 보세요.

| 멈춘 지점 | 가능성이 있는 원인 | 다음 확인 |
| --- | --- | --- |
| 공유 메뉴에 파일이 안 보임 | 저장 위치, 접근 권한, 파일 선택 방식 | 파일 관리 앱에서 실제로 열리는지 확인 |
| 전송 중 중단되거나 대기 | 연결 상태, 공유 앱, 파일 크기·형식 조건 | 작은 파일로 같은 경로를 다시 시험 |
| 보낸 뒤 상대방이 열지 못함 | 링크 권한, 만료, 받는 쪽 앱·형식 | 상대방에게 표시된 오류 문구 확인 |

이때 화면에 나온 정확한 오류 문구를 남겨두면 도움이 됩니다. '전송 실패'와 '접근 권한이 없습니다'는 같은 문제가 아닙니다. 앱이 파일 크기나 형식 제한을 안내한다면 그 앱의 공식 도움말이나 전송 화면의 조건을 기준으로 판단하세요. 모든 메신저·메일 서비스에 통하는 하나의 용량 제한은 없습니다.

## 파일이 선택되지 않는다면 전송보다 원본 위치

사진 앱에서는 보이지만 파일 첨부 창에는 나타나지 않는 경우가 있습니다. 파일이 기기 안에 완전히 저장된 상태인지, 클라우드에서 미리보기만 보여주는 상태인지부터 구분하세요. 해당 파일을 **원래 앱에서 열고 끝까지 표시되는지** 확인합니다. 미리보기는 가능해도 실제 다운로드가 끝나지 않았다면 첨부 단계에서 막힐 수 있습니다.

앱에 파일 접근 권한을 주지 않은 경우도 고려할 수 있습니다. 다만 처음부터 모든 사진과 파일에 광범위한 접근을 허용할 이유는 없습니다. 파일을 선택할 때 제공되는 제한된 선택 기능이 있다면 그것부터 이용하고, 권한을 변경했다면 테스트 후 필요한 범위로 되돌립니다.

다운로드한 문서의 저장 장소가 헷갈린다면 [휴대폰에서 다운로드한 파일을 찾는 방법](/blog/phone-downloaded-file-not-found/)을 먼저 확인해 파일 위치와 형식을 파악할 수 있습니다.

## 작은 파일은 보내지는데 원본만 실패할 때

같은 앱과 같은 상대방에게 텍스트 문서나 작은 사진 한 장을 먼저 보내 봅니다. 작은 파일은 성공하고 특정 동영상이나 큰 문서만 실패한다면 연결 전체가 끊겼다고 단정하기 어렵습니다. **문제가 되는 파일의 크기, 확장자, 손상 여부, 해당 서비스의 첨부 조건**을 차례로 봐야 합니다.

파일 이름을 바꾸는 것은 이름 표시 문제를 시험하는 데 그치며, 확장자를 억지로 바꾼다고 내부 형식이 변하지 않습니다. 원본을 다른 앱에서도 열 수 있는지 확인하고, 필요하면 보낼 목적에 맞는 복사본을 만들어 변환하세요. 개인 사진이나 문서를 출처를 알 수 없는 온라인 변환 서비스에 무작정 올리지는 않습니다.

작은 파일도 모두 실패한다면 같은 앱의 다른 대화에서 재현되는지, 다른 연결 환경에서는 달라지는지 **한 번에 한 조건씩** 비교합니다. 이동통신망과 와이파이를 번갈아 시험할 때는 대용량 데이터 사용량에도 주의하세요. 한 앱에서만 실패한다면 기기 전체 초기화보다 해당 앱의 상태와 공식 안내를 확인하는 편이 문제 범위를 정확히 좁힙니다.

## '보냈다'와 '상대가 볼 수 있다'는 다른 상태

파일 자체를 첨부한 것인지 클라우드 링크를 공유한 것인지 확인하세요. 링크 공유는 상대방이 접근 권한을 가져야 열립니다. 다른 계정으로 로그인돼 있거나 조직 계정 전용 공유, 링크 만료 같은 조건 때문에 전송은 성공해도 열람은 막힐 수 있습니다.

상대방에게는 **'파일이 아예 안 보인다'**, **'권한 요청 화면이 뜬다'**, **'다운로드는 되지만 열리지 않는다'** 중 어느 상태인지 물어보세요. 각각은 전달, 접근 권한, 파일 형식 문제에 가깝습니다. 권한 문제를 해결한다고 곧바로 '링크가 있는 모든 사람에게 공개'로 바꾸면 의도하지 않은 사람도 자료를 볼 수 있습니다. 공유 대상과 자료 민감도를 고려해 접근 권한을 최소한으로 부여하세요.

다운로드가 끝났는데 열리지 않는 파일은 받는 사람의 기기에서 지원하는 형식인지, 전송 중 파일이 손상되지 않았는지도 살펴볼 수 있습니다. 원본과 받은 파일의 이름·크기를 비교하되, 크기가 같다는 이유만으로 무결성이 보장되는 것은 아닙니다.

## 재설치·초기화 전에 남길 것

전송 실패를 해결하려고 앱 데이터를 바로 삭제하거나 휴대폰을 초기화하는 것은 과한 조치입니다. 앱 안에만 저장된 초안·임시 파일이 사라질 수 있기 때문입니다. 문제가 시작된 시점, 파일 유형, 사용한 앱, 연결 상태, 화면 메시지, 작은 테스트 파일의 성공 여부를 적어두면 원인 파악이나 고객지원 문의에도 도움이 됩니다.

여러 수단을 시도해도 같은 파일만 실패한다면 파일의 정상 열림 여부와 별도 보관본을 확인한 뒤 공식 앱 지원 경로를 이용하세요. 급한 전송이라면 승인된 다른 공유 수단으로 **원본의 복사본**을 전달할 수 있지만, 업무 자료나 민감한 문서는 허용된 채널과 접근 권한을 지키는 것이 우선입니다.

공유 문제의 해결은 전송 버튼을 다시 누르는 데 있지 않습니다. **어느 단계에서 실패했는지 확인하고, 단 하나의 조건을 바꿔 결과를 비교하는 것**이 데이터를 지키면서 시간을 줄이는 방법입니다.
