휴대폰을 컴퓨터에 꽂았는데 충전 표시만 뜨고 사진이나 문서 폴더가 보이지 않는다면, 파일이 사라졌다고 생각할 필요는 없습니다. **충전이 되는 것과 컴퓨터가 파일 전송 장치로 인식하는 것은 서로 다른 상태**입니다. 케이블이 데이터 통신을 지원하지 않거나, 휴대폰이 충전 모드로 연결되어 있거나, 컴퓨터 쪽에서 장치를 열지 못하는 경우가 각각 다르게 나타납니다.

해결 순서는 케이블과 연결 상태를 살펴본 다음 휴대폰의 전송 허용 여부를 확인하고, 마지막에 컴퓨터의 인식 문제를 점검하는 것입니다. 이 과정에서 원본 사진을 지우거나 초기화할 이유는 없습니다.

## 충전은 되는데 파일이 안 보인다면 연결 단계부터

USB 연결 문제는 증상에 따라 확인 지점이 달라집니다.

| 화면에서 보이는 상황 | 우선 살펴볼 곳 |
| --- | --- |
| 휴대폰에 충전 표시만 뜨고 전송 관련 알림이 없음 | 데이터 전송 지원 케이블, 포트, 잠금 상태 |
| 휴대폰에는 파일 전송 선택지가 있는데 컴퓨터에 목록이 없음 | 전송 모드 선택 여부, 컴퓨터의 장치 인식 |
| 컴퓨터에 휴대폰 이름은 보이지만 내부가 비어 있음 | 잠금 해제·접근 허용 상태, 연결 재시도 |
| 사진은 가져오지만 다른 앱의 문서가 안 보임 | 운영체제별 접근 범위와 앱 파일 공유 방식 |

처음부터 드라이버를 여러 개 설치하거나 컴퓨터 설정을 초기화하면 비교 기준을 잃습니다. **같은 휴대폰·같은 컴퓨터를 유지한 채 케이블 한 개만 바꿔서** 동작이 달라지는지 보는 방식이 원인 구분에 도움이 됩니다.

## 충전 전용 케이블인지 모양만 보고 알 수는 없다

USB 케이블은 단자가 같아 보여도 지원하는 기능이 다를 수 있습니다. 일부 케이블은 충전에만 사용할 수 있어 전원이 공급되더라도 데이터 전송이 작동하지 않습니다. 따라서 휴대폰이 충전된다는 사실만으로 케이블의 데이터 기능까지 정상이라고 판단하면 안 됩니다.

가능하다면 **다른 기기에서 파일 전송이 된 적 있는 케이블**로 시험하세요. USB 허브나 모니터의 확장 포트를 거치고 있다면 컴퓨터 본체의 다른 포트로 직접 연결해 보는 것도 구분에 도움이 됩니다. 한 가지를 바꿀 때마다 휴대폰의 전송 알림과 컴퓨터 탐색기에 변화가 있는지 기록합니다.

포트에 이물질이 보이거나 단자가 흔들린다면 억지로 밀어 넣지 마세요. 금속 도구를 넣어 청소하거나 젖은 상태에서 시험하는 것도 피해야 합니다. 여러 케이블에서 접촉이 불안정하다면 연결을 중단하고 제조사 점검 안내를 확인해야 합니다.

## 안드로이드는 '충전' 상태에서 파일 전송을 따로 선택할 수 있다

안드로이드 휴대폰은 USB를 꽂았다고 자동으로 파일 전체를 열어 주지 않을 수 있습니다. 기기를 잠금 해제하고 연결 알림을 확인해 보세요. 제조사와 운영체제에 따라 문구는 다르지만 **USB로 충전 중인 기기**와 관련된 알림에서 **파일 전송** 용도를 선택하는 흐름이 제공될 수 있습니다.

Google의 [Android 공식 파일 전송 도움말](https://support.google.com/android/answer/9064445?hl=ko) 역시 Windows 컴퓨터에 연결할 때 잠금 해제, USB 알림 확인, 파일 전송 선택을 안내합니다. 휴대폰에 이 메뉴가 없다고 해서 모든 기기에 동일한 화면이 있어야 한다고 생각하지 마세요. 연결 상황과 제조사 설정에 따라 보이는 선택지가 다릅니다.

전송 모드를 선택한 뒤 컴퓨터에서 새 장치가 나타나는지 확인합니다. 여전히 보이지 않는다면 같은 알림을 반복해서 누르기보다, 다른 데이터 케이블을 연결했을 때도 같은지 비교해야 합니다.

## 아이폰의 사진 가져오기와 안드로이드 파일 탐색은 같지 않다

아이폰을 사용하는데 안드로이드처럼 내부 폴더 전체가 보이지 않는다고 해서 곧장 연결 실패라고 판단해서는 안 됩니다. 아이폰에서 컴퓨터로 사진을 가져오는 방식과 앱에서 만든 문서를 공유하는 방식은 서로 다를 수 있습니다. 컴퓨터를 신뢰할지 묻는 안내가 뜬다면 **내가 관리하는 신뢰 가능한 컴퓨터인지** 확인한 다음 진행해야 합니다.

사진을 옮기려는 목적이라면 사용 중인 macOS 또는 Windows의 공식 사진 가져오기 절차를 따르고, 특정 앱의 문서가 목적이라면 그 앱이 컴퓨터 파일 공유를 지원하는지 따로 확인합니다. 임의의 PC에서 접근 허용을 누르거나 낯선 프로그램에 모든 파일 접근을 주는 것은 문제 해결보다 개인정보 노출 위험을 키울 수 있습니다.

## 휴대폰에선 전송을 허용했는데 컴퓨터에만 안 나타날 때

이 단계에서는 휴대폰 설정을 더 변경하기 전에 컴퓨터 쪽에 장치가 어떤 이름으로 나타나는지 확인하세요. 장치 이름은 보이지만 파일 창이 자동 실행되지 않는 것인지, 장치 자체가 전혀 나타나지 않는 것인지부터 나눕니다.

장치가 보인다면 파일 탐색기나 해당 운영체제의 가져오기 프로그램을 직접 열어 확인합니다. 장치가 전혀 보이지 않는다면 컴퓨터의 다른 USB 포트로 옮겨 보고, 가능한 경우 같은 케이블·휴대폰을 다른 신뢰할 수 있는 컴퓨터에 연결해 결과를 비교합니다.

- 다른 컴퓨터에서 정상이라면 첫 번째 컴퓨터의 인식·소프트웨어 환경을 살필 근거가 생깁니다.
- 어느 컴퓨터에서도 안 되지만 케이블 교체 후 달라진다면 케이블이 유력합니다.
- 특정 휴대폰만 계속 실패한다면 해당 기기의 USB 연결 상태와 제조사 지원 절차를 확인해야 합니다.

운영체제별 드라이버나 전송 프로그램을 설치해야 하는 환경도 있으나, 출처가 불명확한 드라이버 파일을 내려받지는 마세요. 제조사와 운영체제의 공식 안내를 기준으로 진행합니다.

## 파일을 찾았으면 '이동' 대신 작은 파일 복사로 확인

컴퓨터에 폴더가 표시됐다고 대량의 사진을 바로 잘라내기·이동하지 마세요. 작은 사진이나 중요하지 않은 문서 하나를 **복사**한 뒤 컴퓨터에서 실제로 열리는지 확인하면, 보이는 목록만 정상인지 파일 읽기까지 가능한지 알 수 있습니다.

연결 중 파일 복사가 멈춘다면 반복해서 케이블을 뽑기보다 먼저 진행 상태를 확인하고 안전하게 연결을 종료해야 합니다. 연결이 자꾸 끊기는 상태에서 대용량 복사를 계속 시도하면 불완전한 복사본이 쌓여 어떤 파일이 정상인지 구분하기 어려워집니다. 원본이 필요한 상황에서는 휴대폰 파일을 그대로 보존하고, 컴퓨터에 옮긴 복사본이 정상인지 검증한 뒤 정리합니다. 파일 공유 앱이나 상대방의 접근 권한에서 문제가 나는 경우에는 [휴대폰 파일 공유 실패를 구분하는 방법](/blog/phone-file-sharing-failed-check/)처럼 전송 뒤 단계를 별도로 살펴야 합니다.

USB 파일 전송이 안 될 때 가장 피해야 할 행동은 **충전 여부 하나만 보고 고장이라고 단정하거나, 원본을 삭제한 뒤 다시 연결하는 것**입니다. 케이블 → 잠금·허용 상태 → 전송 모드 → 컴퓨터 인식 순으로 범위를 좁히면 무엇을 바꿨을 때 문제가 풀렸는지도 남길 수 있습니다.
