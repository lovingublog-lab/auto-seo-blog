휴대폰 번호를 바꾼 뒤 문자 인증은 되는데 PASS 전자서명만 실패한다면, **새 번호로 문자를 받는 것과 기존 PASS 인증서를 계속 사용하는 것은 다른 문제**입니다. PASS 인증서 공식 FAQ는 **번호를 변경하면 기존 인증서를 이용할 수 없고 새로 발급받아야 한다**고 안내합니다. 번호가 바뀐 직후에는 문자 수신을 시험하는 데서 멈추지 말고, 실제 사용 중인 통신사 회선과 PASS 앱, 인증서 상태를 차례로 확인해야 합니다.

여기서는 본인 명의의 번호를 정상적으로 변경한 뒤 **본인이 사용하는 PASS 인증서**를 다시 연결하는 과정을 다룹니다. 인증문자가 아예 도착하지 않는다면 [휴대폰 인증번호 미수신 원인](/blog/sms-verification-code-not-arriving/)을 별도로 점검하세요. 다른 사람 명의로 인증을 대신하는 방법은 다루지 않습니다.

## 문자 본인확인과 PASS 인증서는 별개의 성공 신호다

은행이나 공공서비스의 로그인 화면에서 '휴대폰 인증'을 누른 뒤 문자를 받아 입력하는 과정과, PASS 앱의 인증서로 전자서명하는 과정은 같은 절차가 아닙니다. 그래서 한쪽이 성공해도 다른 쪽이 실패할 수 있습니다.

| 확인 결과 | 의미 | 다음 행동 |
| --- | --- | --- |
| 새 번호로 통화·문자는 되지만 본인확인 실패 | 가입 명의나 통신사 선택 문제일 수 있음 | 회선 가입 정보와 서비스 인증 선택을 대조 |
| 문자 본인확인은 성공, PASS 인증서만 실패 | 기존 인증서가 번호 변경으로 사용할 수 없을 수 있음 | 현재 회선의 PASS에서 인증서 발급 상태 확인 |
| PASS 앱 자체의 등록·로그인이 진행되지 않음 | 인증서 이전 단계에서 막힌 상태 | 앱의 가입·본인확인 단계부터 복구 |
| PASS 인증서 발급 성공, 특정 사이트만 실패 | 해당 사이트의 인증 요청이나 사용 조건 문제 가능 | 다른 요청과 비교하고 이용기관에 문의 |

새 번호를 이전 번호와 헷갈리지 않게 적어두되, 전체 주민등록번호나 인증 PIN을 메모장·상담 메시지에 함께 보관하지 마세요.

## 통신사가 그대로인지 바뀌었는지가 갈림길

[PASS 인증서 공식 자주 묻는 질문](https://www.passauth.co.kr/question)은 번호 변경 후 기존 인증서를 재사용할 수 없다고 설명하면서, **통신사가 같을 때는 인증서 재발급**, **통신사도 변경되었다면 해당 통신사의 인증 앱을 설치한 후 새 인증서 발급**으로 경로를 구분합니다.

예를 들어 기존 번호와 새 번호가 같은 통신사 회선에 속한다면, 현재 PASS 앱에서 인증서 상태와 재발급 기능을 확인하는 쪽이 맞습니다. 번호이동으로 통신사가 달라졌다면 예전 통신사의 앱이나 인증서를 붙잡고 반복 시도하지 말고, 새 통신사에서 사용할 앱·인증서 발급 조건을 확인해야 합니다. 알뜰폰 가입자는 통신사 브랜드와 실제 망 선택이 다를 수 있으므로 [알뜰폰 본인확인에서 통신사·명의를 확인하는 방법](/blog/mvno-phone-verification-carrier-selection-name-mismatch/)도 참고할 수 있습니다.

이 단계에서 필요한 준비 정보는 **현재 번호, 실제 가입 통신사, 가입자 명의, 사용 중인 휴대폰**입니다. 통신사 이름을 짐작하지 말고 가입 안내서 또는 공식 고객센터에서 확인하세요.

## 기존 인증서를 되살리는 것이 아니라 새 상태를 만든다

새 회선에서 통화·문자 수신이 정상인지 확인한 다음, 공식 앱 설치 경로로 PASS를 확인합니다. 등록이나 본인확인이 막히면 인증서 화면을 계속 찾아 헤매지 말고 **PASS 앱의 본인확인 단계**로 돌아가세요.

앱이 정상 작동하고 본인 확인이 가능하다면, PASS 인증서 서비스에서 관리·재발급 경로를 확인합니다. 공식 FAQ에는 인증서 관리에서 재발급할 수 있다고 안내하지만, 앱 버전과 통신사에 따라 화면 표현이 다를 수 있습니다. 안내받은 PIN 또는 생체인증 등 공식 인증 방법으로 절차를 진행하고, 발급 완료 안내와 인증서 상태를 확인합니다.

여기서 주의할 점은 **공동인증서 파일을 휴대폰으로 복사하는 절차를 PASS 인증서에 적용하지 않는 것**입니다. 발급·저장·관리 방식이 다른 인증수단이므로, PASS 인증서에 '파일 이동' 메뉴가 없다고 고장으로 판단하면 안 됩니다.

## 발급에 성공했는데 원래 사이트가 여전히 막힌다면

인증서를 새로 발급받은 다음에는 원래 로그인을 시도하던 서비스로 돌아가 **새 번호와 현재 통신사로 인증 요청을 다시 시작**합니다. 이전 요청 화면이 열린 채라면 번호 변경 전의 정보나 만료된 요청이 남아 있을 수 있습니다. 이미 사용한 인증요청을 무한히 다시 누르지 말고 새 요청을 진행하세요.

이때 문제가 갈리는 곳을 기록해두면 도움이 됩니다.

- PASS 앱에서 인증 요청 자체가 보이지 않으면 요청한 사이트의 번호·통신사 선택과 앱 등록 회선을 다시 확인합니다.
- 앱에서 승인했는데 사이트가 완료로 넘어가지 않으면 사이트의 재시도 안내와 요청 유효 여부를 확인하고, 필요할 때 해당 사이트 고객센터에 문의합니다.
- 새 번호의 가입 명의가 조회되지 않거나 PASS 앱 가입이 거절되면 인증서 재발급을 반복하지 말고 **현재 통신사에 가입 명의·회선 상태**부터 확인합니다.
- 앱에서 인증서 발급이 거절되면 표시된 오류 유형만 정리해 PASS 공식 지원 채널에 문의합니다. PIN·인증번호·신분증 전체 사진은 전달하지 않습니다.

## 복구가 끝났는지는 실제 전자서명으로 판별한다

완료 조건은 앱 설치 성공이 아닙니다. **새 회선에서 본인확인이 되고 → 현재 통신사의 PASS 인증서가 정상 발급·표시되며 → 원래 필요한 사이트에서 전자서명이나 로그인이 통과하는 상태**여야 합니다. 특히 사용하려는 기관이 PASS 인증서를 지원하는지, 다른 종류의 인증서를 요구하는지도 구분해야 합니다.

번호 변경과 함께 휴대폰까지 교체했다면 앱의 다른 로그인·보안 설정에도 별도 재등록이 필요할 수 있습니다. 다만 'PASS 인증서를 재발급했다'는 이유만으로 정부24, 은행, 공동인증서까지 자동으로 옮겨졌다고 가정하지 마세요. 각각 필요한 서비스에서 실제 로그인 성공을 확인하면 복구 범위를 분명하게 마칠 수 있습니다.
