스마트폰을 눌러도 반응하지 않으면 화면이 고장 났다고 생각하기 쉽습니다. 그러나 **화면 전체가 멈춘 상태**, **특정 위치만 눌리지 않는 상태**, **앱 하나에서만 반응하지 않는 상태**는 확인할 지점이 다릅니다. 같은 '터치 안 됨'이라도 문제 범위를 나누지 않고 초기화부터 하면 중요한 데이터만 잃을 수 있습니다.

지금 당장 할 일은 여러 설정을 바꾸는 것이 아닙니다. **반응하지 않는 범위와 발생 조건을 기록하고, 손쉽게 되돌릴 수 있는 조치부터 한 번씩 시험**하는 것입니다. 화면이 깨졌거나 기기가 과열되는 상황이라면 테스트를 계속하는 대신 사용을 중단해야 할 수도 있습니다.

## 화면 전체가 멈췄는지, 특정 구역만 반응하지 않는지

화면이 켜지고 알림도 바뀌는데 손가락 입력만 먹지 않는다면 표시 기능과 터치 입력 기능이 서로 다르게 작동하고 있을 가능성이 있습니다. 반대로 화면 자체가 검게 나오거나 깜박인다면 터치만의 문제라고 단정하기 어렵습니다.

가능하면 잠금화면, 홈 화면, 설정 화면처럼 **서로 다른 화면**에서 같은 위치가 눌리는지 비교해 보세요. 비밀번호나 패턴을 반복 입력할 필요는 없습니다. 입력이 가능한 화면에서 위아래로 짧게 스크롤하거나 선택할 수 있는 항목을 눌러 반응 범위를 확인하는 정도면 됩니다.

- **전체 화면에서 아무 입력도 안 됨:** 일시적인 시스템 멈춤, 입력 장치 이상, 화면 손상을 함께 고려합니다.
- **항상 같은 가장자리나 줄에서 안 됨:** 앱보다 화면 특정 구역의 문제인지 살펴볼 이유가 큽니다.
- **특정 앱의 특정 버튼만 안 됨:** 버튼이 비활성화된 조건, 앱 오류, 화면 배치 문제일 수 있습니다.

특정 구역이 반복적으로 반응하지 않는다면 같은 지점을 세게 누르거나 두드리지 마세요. 충격을 더해 해결되는 종류의 점검이 아닙니다.

## 앱 하나에서만 생긴 문제라면 화면을 교체할 단계가 아니다

예를 들어 메신저의 전송 버튼은 눌리지 않지만 홈 화면과 다른 앱의 같은 위치는 정상적으로 반응한다면, 디스플레이 전체의 입력 불량보다 그 앱 안의 상태를 살펴볼 가치가 있습니다.

이때는 앱을 닫았다가 다시 열고, 특정 화면에서만 문제가 생기는지 비교합니다. 로그인 직후, 파일을 불러올 때, 팝업이 떠 있을 때처럼 **멈추는 상황이 일정한지** 적어두면 앱 업데이트나 고객지원 문의에서도 단서가 됩니다.

반응이 늦어서 연속으로 터치하는 것과 아예 인식되지 않는 것은 다릅니다. 버튼을 여러 번 누른 뒤 한꺼번에 동작한다면 기기 처리 지연이나 네트워크 응답을 기다리는 상황도 생각해야 합니다. 인터넷이 필요한 동작만 늦는다면 네트워크를 바꿔 한 번 비교하되, 화면 전체의 터치 문제라고 바로 연결하지는 마세요.

## 물기·보호필름·충전 환경을 한 번에 바꾸지 않는 이유

손이나 화면에 물기가 남아 있거나, 보호필름 가장자리가 들떠 있거나, 특정 충전 환경에서만 입력이 불안정하다면 외부 조건을 분리해 시험할 수 있습니다.

손과 화면 표면을 부드러운 마른 천으로 닦은 뒤 완전히 마른 상태에서 확인합니다. 세정액을 화면 틈에 흘리거나 날카로운 도구로 필름을 들어 올릴 필요는 없습니다. 필름이 깨져 있거나 두껍게 겹쳐져 있다면 제거 전 손상 위험과 보증·부착 상태를 함께 고려하세요.

충전할 때만 이상하다면 **충전기를 뽑은 상태와 연결한 상태**를 비교해 보세요. 충전선이 뜨겁거나 손상됐거나 연결부에서 냄새가 나면 비교 시험을 계속하지 말고 사용을 중단합니다. 안전이 의심되는 충전기를 다른 기기에 꽂아 재현 실험을 해서는 안 됩니다.

여러 변수를 동시에 바꾸면 어느 변화가 영향을 줬는지 알 수 없습니다. 특히 화면 필름을 떼고 앱을 삭제하고 설정까지 초기화하는 식의 연속 조치는 피하는 편이 합리적입니다.

## 재시작은 시도할 수 있지만, 초기화는 전혀 다른 조치다

입력이 잠깐 멈춘 상태라면 기기 모델에 맞는 **일반 재시작이나 강제 재시작**이 일시적인 시스템 오류를 해소하는지 볼 수 있습니다. 버튼 조합은 제조사·모델에 따라 다르므로 해당 제조사 공식 안내를 확인하세요. 재시작은 보통 공장 초기화와 다르지만, 저장하지 않은 작업 내용은 사라질 수 있습니다.

재시작 뒤에 정상으로 돌아왔다면 바로 완료로 판단하지 말고 언제 재발하는지 확인합니다. 게임 실행 중, 발열이 높을 때, 충전 중처럼 일정한 조건에서 반복되는지 기록하는 쪽이 원인을 찾는 데 도움이 됩니다.

반면 **공장 초기화, 기기 데이터 삭제, 무조건적인 앱 데이터 삭제**는 문제 확인 단계에서 가볍게 선택할 조치가 아닙니다. 초기화를 하기 전에 백업의 존재뿐 아니라 필요한 사진·문서·인증 수단을 다른 곳에서 실제로 열 수 있는지 확인해야 합니다. 저장공간 부족이 함께 의심될 때도 삭제보다는 [삭제 전 파일 복구 가능성을 나누는 기준](/blog/smartphone-storage-cleanup-before-delete/)을 참고해 데이터를 보호하세요.

## 터치가 전혀 안 돼 잠금 해제도 못 하는 경우

정상적인 입력이 불가능하면 백업 앱을 설치하거나 복구 설정을 직접 바꾸기도 어렵습니다. 이때 인터넷에서 본 임의의 복구 프로그램을 설치하거나, 기기를 초기화하면 저절로 고쳐질 것이라고 기대하는 방식은 위험합니다.

화면이 보이고 기기가 켜진다면 제조사가 안내하는 지원 절차와 수리 접수 방법을 확인하세요. 외부 입력 장치를 연결하는 방법이 일부 기기에 제공되더라도 모든 기기에서 작동하는 것은 아니며 잠금·보안 설정에 따라 제한될 수 있습니다. 사용할 수 있는 대체 입력 경로가 확인되지 않았다면 억지로 진행하지 않아도 됩니다.

수리 전에는 가능하면 계정의 백업·동기화 상태와 기기 잠금 해제 가능 여부를 정리해 두세요. 수리 과정에서 데이터 접근이나 보존이 보장되는 것은 아니므로 접수 전에 데이터 처리 방침을 문의해야 합니다.

## 화면 균열·배터리 부풀음·이상 발열은 중단 신호다

떨어뜨린 뒤부터 터치가 특정 위치에서 끊기거나 화면 유리에 균열이 났다면 외부 조건을 바꿔도 해결되지 않을 수 있습니다. 화면 가장자리가 들뜨거나 기기 뒷면이 부풀어 보이고, 이상한 냄새 또는 심한 발열이 함께 나타난다면 더 사용하거나 충전하지 말고 제조사 점검을 받으세요.

액체가 들어간 것으로 의심되는 기기는 열풍으로 말리거나 충전으로 상태를 시험하지 않습니다. 안전한 보관·점검 방법을 제조사에 확인하는 것이 우선입니다.

**앱에서만 생기는 문제인지 → 화면 전체 또는 일정 구역의 문제인지 → 물기·필름·충전 조건에 따른 차이인지**를 기록해 두면 불필요한 초기화를 줄이고 상담할 때도 상황을 정확히 전달할 수 있습니다. 어떤 조건에서도 같은 위치가 계속 반응하지 않는다면 설정을 계속 바꾸기보다 공식 점검이 필요한 시점입니다.
