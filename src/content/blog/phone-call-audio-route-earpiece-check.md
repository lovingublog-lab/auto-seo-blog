통화가 연결됐는데 상대 목소리가 거의 들리지 않는다면 음량을 끝까지 올리거나 휴대폰을 초기화할 단계는 아닙니다. **귀에 대고 들을 때만 조용한지, 스피커폰에서도 조용한지, 특정 이어폰을 연결할 때만 그런지** 비교하면 문제 범위를 상당히 좁힐 수 있습니다. 통화 소리가 어디로 나가고 있는지와 상대방의 음성이 제대로 전송되는지는 별개의 문제입니다.

다음 점검은 통화가 끊겨도 곤란하지 않은 시간에, 협조할 수 있는 상대와 짧게 진행하세요. 한 번에 하나만 바꿔야 어떤 조치가 영향을 줬는지 알 수 있습니다.

## 같은 통화에서 듣는 방법을 바꿨을 때

수화부는 휴대폰을 귀에 댔을 때 소리를 내는 작은 출력 부분입니다. 스피커폰은 보통 다른 출력 경로를 쓰고, 무선 이어폰은 다시 별도 경로로 소리가 전달됩니다. 같은 통화에서 경로를 바꾸어 보면 증상의 차이가 드러납니다.

| 실제로 나타나는 상태 | 우선 의심할 범위 |
| --- | --- |
| 귀에 대면 안 들리지만 스피커폰에서는 또렷함 | 수화부 쪽 출력·가림·장치 상태 |
| 휴대폰에서는 들리는데 블루투스 이어폰에서만 조용함 | 이어폰 연결 또는 통화 오디오 경로 |
| 수화부와 스피커폰 모두 상대 목소리가 끊김 | 통신 품질, 상대 기기, 통화 앱 또는 서비스 |
| 상대는 내 목소리를 못 듣지만 나는 상대를 들음 | 내 마이크·음소거·송신 경로 — 다른 증상 |

이 표만으로 부품 고장을 확정할 수는 없습니다. 다만 **한 출력에서만 실패하는지, 모든 출력에서 실패하는지**를 구분하면 무작정 설정을 건드리지 않아도 됩니다.

## 화면에 연결된 오디오 기기가 남아 있을 수 있다

무선 이어폰을 가방에 넣었거나 차량에서 내렸는데도 휴대폰이 그 기기를 통화 출력 대상으로 유지하는 경우가 있습니다. 이때 화면에 통화가 연결됐다고 표시되어도 소리는 손에 든 휴대폰이 아닌 다른 곳으로 나갈 수 있습니다.

통화 화면에 오디오·스피커·블루투스 기기 선택 항목이 있는지 확인하고, 현재 선택된 대상을 살펴보세요. 메뉴 이름과 표시 방식은 휴대폰 모델과 통화 앱에 따라 다릅니다. **연결 대상을 휴대폰 본체로 한 번 바꾼 뒤** 같은 말을 다시 들어봅니다. 정상으로 돌아오면 수화부 고장보다 연결 경로를 우선 점검할 근거가 생깁니다.

블루투스를 끄는 방법으로 비교할 수도 있지만, 운전 중이거나 다른 연결 기기에 의존하는 상황이라면 통화를 마치고 안전한 곳에서 시험해야 합니다. 이어폰 자체가 불규칙하게 끊긴다면 [블루투스 이어폰의 연결 문제를 나누어 점검하는 글](/blog/bluetooth-earbuds-disconnect-check/)이 다음 단계에 가깝습니다.

## 스피커폰만 정상이라면 수화부 주변을 살핀다

귀에 대고 들을 때만 유난히 작다면 휴대폰 위쪽의 수화부를 손가락, 케이스, 보호필름이 가리고 있지 않은지 살펴보세요. 화면 전면의 구멍이나 틈을 임의로 찌르거나 테이프로 오염을 떼어내려고 해서는 안 됩니다. 작은 부품과 방수 구조를 손상시킬 수 있기 때문입니다.

통화 중 음량 버튼을 눌러 변화가 있는지 확인하되, 통화 음량과 동영상 재생 음량은 동일한 설정이라고 가정하지 마세요. **영상 소리는 잘 들리는데 귀에 대고 하는 통화만 작다**는 관찰은 매우 유용합니다. 반대로 영상·알림·통화가 모두 조용하다면 [미디어 소리가 나지 않을 때 출력 경로를 확인하는 방법](/blog/phone-video-no-sound-output-check/)에서 다룬 상황과도 비교할 수 있습니다.

물에 젖었거나 떨어뜨린 직후부터 증상이 시작됐다면 건조기를 대거나 뜨거운 바람으로 말리지 마세요. 발열, 부품 손상 위험이 있으므로 제조사의 점검 기준을 확인해야 합니다.

## 특정 사람과만 통화할 때 문제가 생긴다면

같은 장소에서 서로 다른 상대 두 명과 통화했을 때 결과가 다르다면 내 휴대폰의 수화부만 원인으로 단정하기 어렵습니다. 상대방의 마이크·음소거 상태, 상대방이 사용하는 이어폰, 통화 서비스의 일시적인 연결 상태가 영향을 줄 수 있습니다.

반대로 여러 상대와 통화해도 같은 구간에서 음성이 끊기고, 장소를 옮기거나 연결 방식을 바꾼 뒤 달라진다면 통신 환경도 확인할 필요가 있습니다. 이동 중인 지하 공간이나 신호가 불안정한 장소에서는 먼저 안전하게 이동을 마치고, 안정적인 장소에서 짧게 재통화해 비교하세요. 통화 서비스마다 데이터 통화와 이동통신망 통화의 조건이 다를 수 있으므로 한 앱의 결과를 모든 통화에 일반화하지 않습니다.

## 통화 녹음·영상 테스트로 확정할 수 없는 것

동영상 촬영에서 음성이 잘 녹음된다고 해서 통화 중 쓰는 모든 마이크와 소리 출력 부품이 정상이라는 뜻은 아닙니다. 기기마다 통화·촬영·스피커폰에서 사용하는 마이크와 처리 방식이 다를 수 있습니다. 통화 녹음이 가능한 기기라 하더라도 개인정보와 지역별 규정을 고려해야 하며, 녹음 기능이 없는 환경에서는 시도할 필요가 없습니다.

원인을 기록할 때는 **상대, 장소, 통화 앱, 사용한 출력 기기, 스피커폰 전환 전후** 정도만 남겨도 충분합니다. 같은 조건에서 다시 나타나는지 확인할 수 있는 정보입니다. 개인 대화 내용 자체를 저장하거나 공유할 이유는 없습니다.

## 점검을 중단하고 지원을 받아야 할 신호

여러 상대와의 통화에서 수화부만 계속 작거나 무음이고, 케이스·출력 경로·통화 음량을 확인해도 달라지지 않는다면 제조사 진단이나 서비스센터 점검이 필요할 수 있습니다. 떨어뜨린 뒤 잡음이 생겼거나 발열·물기·단자 손상이 동반될 때도 같은 기준을 적용합니다.

앱 데이터 삭제, 네트워크 설정 초기화, 공장 초기화는 이 단계의 첫 조치가 아닙니다. 특히 계정 복구와 데이터 백업을 확인하지 않은 상태에서 초기화하면 원래 문제보다 복구 비용이 커질 수 있습니다.

**통화 경로별로 소리가 달라지는지 확인한 기록**을 남기면 수화부 문제인지, 무선 기기 연결인지, 통신·상대방 문제인지 설명하기 쉬워집니다. 고장 여부를 서둘러 단정하기보다 재현 가능한 증상을 갖고 다음 점검으로 넘어가세요.
