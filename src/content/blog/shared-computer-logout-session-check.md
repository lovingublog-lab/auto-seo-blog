도서관이나 PC방에서 웹메일·문서·예약 사이트에 로그인한 뒤 ‘로그아웃’ 버튼을 눌렀다면 모든 흔적이 사라졌다고 생각하기 쉽습니다. 하지만 **사이트의 로그인 세션**, **브라우저에 저장된 계정 정보**, **컴퓨터에 내려받은 파일**은 서로 다른 문제입니다. 하나를 끝냈다고 나머지도 자동으로 정리되는 것은 아닙니다.

공용 PC를 떠나기 전에는 ‘사이트에서 나왔는가’와 ‘이 컴퓨터에 내 자료가 남았는가’를 따로 점검해야 합니다. 이미 자리를 떠났다면 할 수 있는 일과 직접 돌아가야만 할 수 있는 일도 구분할 필요가 있습니다.

## 로그아웃 버튼과 브라우저 종료는 같은 조치가 아니다

웹사이트의 로그아웃은 그 서비스의 로그인 상태를 끝내기 위한 행동입니다. 반면 탭을 닫거나 브라우저 창만 종료하는 것은 서비스에 따라 로그인 유지 여부를 바꾸지 않을 수 있습니다. ‘창을 닫았으니 괜찮다’고 판단하지 말고, **사용한 서비스의 계정 메뉴에서 로그아웃이 완료됐는지** 확인하세요.

서로 다른 서비스에 로그인했다면 각각 상태를 점검합니다. 예를 들어 웹메일과 파일 저장 서비스를 별도로 열었다면 한쪽의 로그아웃이 다른 쪽까지 처리한다고 가정하지 않습니다. 브라우저의 새 창에서 같은 사이트를 열었을 때 계정 내용이 바로 보이는지도 단서가 됩니다. 단, 다시 로그인할 필요가 없을 만큼 민감한 화면을 오래 열어두지는 마세요.

로그아웃 후 로그인 화면에 이메일 주소가 표시되는 것만으로 로그인 상태가 남았다고 단정할 수는 없습니다. **주소 자동완성만 남는 경우**와 **비밀번호 또는 인증 없이 실제 계정에 들어가는 경우**는 위험도가 다릅니다. 둘을 혼동해 계정 삭제나 컴퓨터 초기화부터 시도할 이유는 없습니다.

## 브라우저에 저장한 비밀번호·프로필은 별도로 살펴야 한다

로그인 중 브라우저가 ‘비밀번호 저장’이나 ‘이 기기에서 로그인 유지’를 제안했을 때 이를 허용했는지 기억해 보세요. 공용 컴퓨터에서 저장했다면 웹사이트 로그아웃과 별개로 브라우저의 저장된 자격 증명을 점검해야 합니다. 브라우저 설정 이름과 삭제 경로는 버전에 따라 다르지만, 일반적으로 **비밀번호 관리 또는 자동완성**, **프로필 및 동기화**, **사이트 데이터** 항목이 점검 대상입니다.

특히 개인 브라우저 계정으로 공용 PC의 브라우저 프로필에 로그인했다면 문제가 커질 수 있습니다. 웹사이트 하나가 아니라 즐겨찾기나 동기화된 정보가 해당 브라우저 프로필에 연결됐을 수 있기 때문입니다. 이때는 브라우저 프로필의 로그아웃·동기화 해제 상태를 확인하고, 공식 계정 관리 화면에서 해당 기기가 계속 연결돼 있는지 살펴봅니다.

공용 PC 전체의 방문 기록이나 다른 사용자의 계정 데이터를 무작정 지우지는 마세요. 관리자가 운영하는 기기라면 사용 범위 안에서 자신의 로그인 정보만 정리하고, 불가능한 조치는 관리자에게 요청해야 합니다.

## 내려받은 파일과 인쇄 대기열은 로그인과 독립적이다

이력서, 예약 확인서, 신분 확인 자료, 업무 문서를 열면서 ‘다운로드’를 눌렀다면 브라우저에서 로그아웃해도 로컬 파일은 남을 수 있습니다. 사용한 파일 이름과 저장 위치를 확인하고 자신이 내려받은 사본을 정리하세요. 휴지통으로 보냈다면 삭제 처리가 끝났는지도 확인합니다. 단, 공용 PC의 삭제 정책은 운영 환경에 따라 달라 완전 삭제를 보장할 수는 없습니다.

출력 서비스를 이용했다면 프린터에 인쇄물이 남지 않았는지도 확인해야 합니다. 인쇄 작업 대기 화면이나 공용 출력함에 파일이 남는 운영 방식이라면 담당자에게 문의하세요. **개인 파일을 웹에서 열람만 한 상황**과 **파일을 다운로드·출력한 상황**은 점검 범위가 다릅니다.

다음에 공용 PC를 사용해야 한다면 브라우저의 방문자 모드나 개인 정보 보호 창이 있는지 볼 수 있습니다. 이런 방식은 기기에 남는 일반 브라우징 기록을 줄이는 데 도움을 줄 수 있지만 다운로드 파일, 프린터 기록, 기기 관리자가 수집하는 기록까지 없애는 장치는 아닙니다.

## 이미 공용 PC를 떠났을 때 할 수 있는 조치

현장으로 돌아갈 수 없다면 **본인이 소유한 안전한 휴대폰이나 컴퓨터**에서 서비스의 계정·보안 화면을 여세요. 서비스가 로그인된 기기 또는 세션 목록을 제공한다면 이용한 공용 PC로 추정되는 세션을 확인해 로그아웃합니다. 메뉴 명칭과 제공 여부는 서비스마다 다르므로 공식 계정 화면의 안내를 따릅니다.

세션 목록에서 기기가 특정되지 않더라도 모든 기기에서 로그아웃하는 기능이 있다면 영향 범위를 이해한 뒤 사용할 수 있습니다. 개인 기기에서도 다시 로그인해야 할 수 있기 때문입니다. **비밀번호를 브라우저에 저장했거나 남에게 노출된 정황이 있다면** 공식 경로에서 비밀번호를 변경하고, 다른 서비스에서 같은 비밀번호를 사용했는지 확인하세요. 다중 인증을 켜는 것 역시 도움이 되지만 이미 저장된 세션의 종료 여부를 별도로 살펴야 합니다.

로그인하지 않았는데 새로운 접속 알림이 오거나 계정에서 모르는 활동이 보인다면 단순 흔적 정리보다 계정 보호가 우선입니다. [낯선 로그인 알림을 받았을 때 확인하는 순서](/blog/login-alert-not-me-account-safety/)에 따라 로그인 기록과 복구 수단을 점검하세요.

## 다음 번에는 사용 전에 ‘남지 않을 자료’를 정하자

공용 컴퓨터에서 할 수 있는 작업과 개인 기기에서만 해야 할 작업을 나누면 뒤처리가 훨씬 간단해집니다. 단순 일정 조회는 공용 화면에서 하더라도, 민감한 신분증 이미지 업로드나 계정 복구 코드 열람처럼 유출 시 피해가 큰 작업은 가급적 신뢰할 수 있는 개인 기기에서 처리하세요. 파일을 공유하기 전에 화면에 개인정보가 남는지 확인하는 방법은 [화면 캡처 공유 전 정보 점검](/blog/screenshot-sharing-private-info-check/)과도 연결됩니다.

작업을 끝냈을 때는 **서비스별 로그아웃 → 브라우저 저장·프로필 상태 확인 → 다운로드·출력물 점검**의 순서로 마무리합니다. 공용 PC를 떠난 뒤라면 ‘원격에서 세션은 종료할 수 있지만 내려받은 파일은 직접 지울 수 없을 수 있다’는 한계를 받아들이고, 필요하면 시설 관리자에게 정리 방법을 문의해야 합니다. 계정 접근을 끊는 일과 현장에 남은 사본을 관리하는 일은 끝까지 서로 구분해야 합니다.
