eSIM을 설치한 새 휴대폰에서 인터넷은 되는데 은행이나 정부 서비스의 인증문자가 오지 않는다면, 인증번호 재전송을 반복하기 전에 **지금 사용 중인 회선이 어떤 상태인지** 구분해야 합니다. eSIM 프로필이 휴대폰에 보이는 것, 해당 번호의 개통이 완료된 것, 그 번호로 문자를 받을 수 있는 것, 서비스가 가입자 정보를 확인하는 것은 서로 다른 단계입니다.

이 글은 **국내 이동통신 회선으로 eSIM을 개통하거나 번호이동한 뒤** 휴대폰 본인확인이 막힌 상황을 다룹니다. 여행용 데이터 전용 eSIM은 애초에 문자나 국내 본인확인을 지원하지 않을 수 있으므로, 국내 통신사의 일반 음성·문자 회선과 섞어 판단하면 안 됩니다.

## 개통 실패와 인증 실패는 화면에서 다르게 나타난다

휴대폰에서 현재 회선으로 일반 통화, 일반 문자, 모바일 데이터를 각각 사용할 수 있는지 기록해 보세요. 통신사는 이 세 기능의 정상 작동을 개통 뒤 확인 지점으로 안내합니다. 예를 들어 [KT의 eSIM 개통 안내](https://shop.kt.com/preorder/preorderGuideInfo.do?preorderNo=396308)는 설치 후 재부팅하고 통화·문자·인터넷을 점검하도록 설명합니다.

| 확인 결과 | 의심할 단계 | 다음 행동 |
| --- | --- | --- |
| eSIM은 목록에 있으나 통화·문자·데이터가 모두 안 됨 | 설치 완료 또는 개통·회선 활성화 | 개통 완료 안내와 eSIM 활성 상태 확인 후 통신사 문의 |
| 통화는 되지만 일반 문자도 안 옴 | 문자 송수신·단말 설정 | 다른 번호와 일반 SMS 수신 시험, 스팸함·수신 제한 확인 |
| 일반 문자는 오지만 특정 서비스 인증문자만 안 옴 | 발신 서비스·단문 차단·인증 경로 | 해당 서비스의 번호·전송 방식 확인 |
| 인증문자는 오지만 최종 본인확인이 실패 | 가입 명의·통신사 선택·인증 정보 | 현재 회선과 본인확인 화면의 정보를 대조 |

테스트에는 다른 휴대폰에서 보내는 **일반 문자 한 통**을 활용할 수 있습니다. 일반 문자와 본인인증 문자를 구분해 두면 통신망 문제인지 특정 서비스의 발송·인증 문제인지 좁히기 쉽습니다. 일반 SMS 자체가 오지 않는 상황은 [인증문자 미수신의 기본 점검 순서](/blog/sms-verification-code-not-arriving/)도 참고하세요.

## 설치 완료 알림만으로 개통이 끝났다고 보지 않는다

번호이동이라면 기존 통신사 회선이 끊긴 시점, 새 통신사의 개통 완료 안내, 새 단말의 eSIM 설치 완료가 같은 단계는 아닐 수 있습니다. 이동통신사의 신청 이력에서 **처리 중·보류·완료 중 무엇인지** 확인하세요. 한 번 설정에 실패했다고 eSIM을 삭제하고 QR을 반복 등록하는 것은 피해야 합니다. 상품과 사업자에 따라 프로필 재발급 조건이 다릅니다.

새 휴대폰의 무선 연결이 필요한 개통 과정에서는 해당 사업자가 안내한 Wi-Fi 조건을 따르세요. KT는 일부 온라인 개통 절차에서 새 기기를 Wi-Fi에 연결해 eSIM을 다운로드하고, 기존 휴대폰 핫스팟을 이용하지 말라고 안내합니다. 이 조건이 모든 통신사 상품에 동일하게 적용된다는 뜻은 아닙니다.

개통이 완료됐다고 표시됐지만 통신 기능이 동작하지 않는다면 안내에 따라 재부팅해 보고, 여전히 정상 사용이 안 되면 **개통 접수번호·휴대폰 기종·오류 화면·개통 시각**을 정리해 해당 통신사에 문의하세요. 개통 상태를 모른 채 초기화하면 문제의 원인을 확인하기가 더 어려워집니다.

## 듀얼 SIM이라면 데이터 회선과 문자 받을 번호를 따로 본다

실물 유심과 eSIM을 함께 쓰거나 eSIM 두 개를 등록한 기기에서는 휴대폰이 선택한 기본 데이터 회선과 **본인확인에 입력한 전화번호**가 다를 수 있습니다. 인증 요청을 한 번호가 새 eSIM 번호인지, 예전 번호인지 확인하세요. 데이터가 다른 회선을 통해 잘 된다는 사실은 인증 대상 번호의 SMS 수신을 증명하지 않습니다.

휴대폰의 SIM 관리 화면에서 해당 eSIM이 켜져 있는지, 번호가 어떤 회선에 연결되는지 확인합니다. 표시 명칭과 메뉴는 기종·운영체제마다 다를 수 있습니다. 단순 설정 점검을 넘어 프로필을 제거하거나 재다운로드해야 하는 상황이라면 사업자 안내를 받은 다음 진행하세요.

여행자용 eSIM은 더욱 주의해야 합니다. [LG유플러스의 한국 방문자용 eSIM 안내](https://www.lguplus.com/korea-sim/kor/pc/support/faq?tab=esim)는 데이터 전용 상품에 SMS 기능이 없고, 음성·문자 상품도 은행·관공서 본인확인이 제한될 수 있다고 설명합니다. **문자 수신 가능**과 **국내 실명 본인확인 가능**은 같은 의미가 아닙니다.

## 일반 문자까지 정상이라면 가입자 정보와 인증 방식을 대조한다

번호이동 직후 공공기관이나 금융서비스의 본인확인에서 실패할 때는 실제 가입자 명의, 통신사·알뜰폰 구분, 인증 요청 전화번호가 일치하는지 확인하세요. 번호는 그대로여도 **이전 통신사를 계속 선택**하면 조회가 맞지 않을 수 있습니다. 알뜰폰 사용자는 브랜드 이름과 이용 중인 통신망 선택을 혼동하기 쉬우므로 [알뜰폰 인증의 통신사·명의 구분](/blog/mvno-phone-verification-carrier-selection-name-mismatch/)을 참고할 수 있습니다.

또한 PASS 인증서 등 별도로 등록하는 인증수단은 휴대폰 회선이 정상 개통됐다고 자동으로 재발급·복구되는 것은 아닙니다. **휴대폰 본인확인용 SMS**와 **앱에 등록된 전자서명 수단**을 구분해야 합니다. 인증 앱에 과거 회선·단말 정보가 남아 있다면 해당 서비스의 공식 재등록 절차를 확인합니다.

## 실패가 계속되면 문의할 곳을 결정하는 기준

통화와 일반 문자가 모두 실패한다면 **통신사 개통·문자 서비스**를 담당하는 곳에서 회선 상태를 조회받아야 합니다. 일반 문자는 되는데 한 서비스에서만 인증번호가 오지 않는다면 **인증 요청 서비스 운영사**에서 발송 기록과 제한 사유를 확인받는 것이 순서입니다. 문자는 오지만 이름·명의 확인에서 거절된다면 통신사 가입 정보와 해당 본인확인 서비스의 입력 조건을 함께 대조합니다.

문의할 때 주민등록번호 전체나 문자 인증번호를 상담 채팅에 그대로 보내지 말고, 오류 시각과 표시 문구, 회선 종류, 통화·일반 SMS 성공 여부만 우선 전달하세요. 해결 완료 신호는 'eSIM 아이콘이 보임'이 아니라 **내 번호의 통화와 문자 송수신이 되고, 필요한 서비스에서 본인확인까지 정상 완료되는 상태**입니다.
